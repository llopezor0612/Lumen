Conexión y herramientas

Búsqueda web, ejecución de código, imágenes y PDF: no disponibles en esta versión.

Privacidad y almacenamiento

Las conversaciones y preferencias se guardan en este equipo hasta que las elimines. El mensaje, los archivos de texto incluidos y el contexto seleccionado se envían al proveedor configurado. No hay memoria entre conversaciones; las preferencias sí se aplican a todas.

Esta versión está diseñada para uso local individual, sin cuentas. No la expongas a internet.
